Scope, version and attribution

BGC identifiers refer to BEC v11. Matching labels in a later map version do not verify matching boundaries. This browser uses exact identifiers and does not assign a soil moisture regime from map location.

The 2020, 2050 and 2080 projections represent 2011–2040, 2041–2070 and 2071–2100. The original README omits the CSV's 1971–2000 period and inconsistently labels the final projection 2070. This browser preserves the actual six CSV labels.

The published forDRAT table is distinct from the older forestDroughtTool R calculator. No legacy model has been used to recalculate these published results.
